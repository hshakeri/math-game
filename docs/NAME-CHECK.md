# Keybreakers name screen

Screened 2026-11-09 before adding the proposed title to application code. This is a quick naming screen, not a trademark clearance.

Queries: `"Keybreakers" game app`, `site:apps.apple.com "Keybreakers"`, `site:play.google.com "Keybreakers"`, `"Keybreakers" trademark`, `"Keybreakers" site:uspto.gov`, and `"Keybreakers" site:trademarkia.com`.

No obvious exact-name Apple App Store or Google Play listing surfaced in those indexed searches. An exact-name registered trademark did not surface in the indexed search. The [USPTO search application](https://tmsearch.uspto.gov/) opened but returned no readable search results through the research tool; its registry was not exhaustively searched.

A meaningful adjacent conflict did surface: [The Frozen Pond by M. Mars](https://www.adlibris.com/sv/bok/the-frozen-pond-9798178598818) is listed as part of the **Keybreakers** book series. The creator's [public update](https://www.patreon.com/Sunneh/posts/sunnehside-174492382) describes planned JRPG-style animations featuring the Keybreakers. This is close enough to a story-led RPG identity that the title must remain provisional before public release.

Decision for this local design pass: use the user's preferred **Keybreakers: The Goblin’s Gate** as the working title, retain **Castle of Theorems** as the destination, and make no assertion of name availability. Riddlekeep was excluded as requested. No app-store submission, trademark filing, public publication, or git commit was made.
